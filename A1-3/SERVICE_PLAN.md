# Novel Radar 서비스 기획서

## 1. 서비스 개요

**Novel Radar**는 한국의 편/회차 단위 웹소설 유료 결제 환경에서, 사용자가 국내외 작품을 결제하기 전에 작품의 특징, 전개 성향, 독자 매력 포인트, 그리고 끝까지 읽어야만 알 수 있는 호불호/지뢰 요소를 사전에 파악할 수 있도록 돕는 **AI 기반 웹소설 분석·선발대 서비스**입니다.

특히 해외 웹소설(중국 선협·언정, 일본 라노벨·웹소설, 영미권 등)은 원제만 알거나 외국어 리뷰 사이트(NovelUpdates, Reddit, Goodreads 등)에 정보가 흩어져 있어 한국인 독자가 결제 전에 작품을 판단하기 어렵다는 고질적인 문제를 해결합니다.

---

## 2. 서비스 목적 및 핵심 가치

서비스의 목표는 명확한 두 가지 축으로 이루어집니다.

1. **소개 (Discovery):** 좋은 해외·국내 작품의 도입부 설정과 핵심 매력 포인트를 한국 독자에게 소개합니다. 중반 이후의 전개나 핵심 반전은 철저히 배제하여 읽는 즐거움을 보존합니다.
2. **사고 방지 (Risk Prevention):** 연재 중단·장기 휴재 이력, 슬픈 결말·주인공 사망, 억지 전개·자기복제, 혐오 표현처럼 끝까지 따라가 결제해야만 알 수 있는 위험을 결제 전에 알려 독자가 유료 결제 후 낭패를 겪지 않도록 돕습니다.

### 핵심 차별점

* **원어 제목 그대로 검색:** 영어, 중국어, 일본어 등 원작 제목을 번역 없이 그대로 입력할 수 있습니다.
* **한국어 분석 결과 제공:** 해외 웹사이트 및 외국어 리뷰를 검색하더라도 최종 결과는 정제된 한국어로 제공됩니다.
* **한눈에 보는 핵심 키워드 요약:** 메인 장르, 완결/연재 여부, 국내 정식 연재 플랫폼, 대표 호불호 요소를 상단 배지로 즉시 파악할 수 있습니다.
* **26종 호불호 체크리스트 및 결말 스포일러 방지:** 독자들이 가장 민감하게 반응하는 요소를 5개 카테고리 26개 항목으로 전수 판정하며, 새드엔딩/주인공 사망 등 치명적인 결말 요소는 🔒 클릭 블라인드 처리하여 스포일러를 방지합니다.
* **실시간 원형 진행률 스트리밍:** NDJSON 스트리밍 방식을 적용하여 웹 검색(0~35%)부터 AI 분석(40~90%)까지 진행 단계를 시각적 게이지로 안내합니다.

## 3. 타겟 사용자

### 주요 타겟
* 편/회차 단위(회당 100~200원 이상)로 웹소설을 유료 구매하는 **한국인 웹소설 독자**.

### 세부 사용자 페르소나
1. **해외 웹소설 관심 독자:** 중국 언정/선협, 일본 판타지, 영미권 웹소설에 관심이 많으나 외국어 리뷰(NovelUpdates 등)를 직접 찾아보기 번거로운 독자.
2. **지뢰 회피형 독자:** 하렘, NTR, 고구마, 새드엔딩, 연재중단 작품을 극도로 기피하여 결제 전 선발대 리뷰를 반드시 확인하는 독자.
3. **효율적 탐색형 독자:** 수백 편 분량의 장편 소설을 정주행하기 전, 초반 진입장벽과 실제 완결 여부, 국내 정식 서비스처를 먼저 확인하고 싶은 독자.

## 4. 페이지 및 섹션 구성

Novel Radar는 사용자의 편의성을 극대화한 단일 반응형 페이지(Single Page Application)로, 상단 메뉴의 앵커 링크로 부드럽게 스크롤 이동합니다.

### 4.1 홈 (`#home`)
* 서비스 아이덴티티와 핵심 슬로건 전달 ("결제하기 전, 선발대에게 물어보세요").
* 원어 제목 검색 및 지뢰 방지 기능의 가치 소개.
* `작품 분석해보기` CTA 버튼을 통해 `#analyze` 섹션으로 바로 이동.

### 4.2 소개 (`#about`)
* 3대 핵심 가치를 카드 형태로 안내:
  1. **원제 그대로 검색:** 한국어/영어/중국어/일본어 원제 입력 지원.
  2. **한눈에 보는 키워드:** 장르, 연재 상태, 국내 플랫폼, 대표 호불호 요약.
  3. **스포일러 없이 사고 방지:** 초반 전개만 소개하고 결말 요소는 눌러서 확인.

### 4.3 분석하기 (`#analyze`)
* **입력 UI:** 작품명/원제 입력 필드, 원클릭 추천 예시 칩(`诡秘之主`, `Lord of the Mysteries`, `전지적 독자 시점`, `나 혼자만 레벨업`), `분석하기` 버튼.
* **진행률 UI:** 원형 Progress Ring 게이지(0~100%)와 현재 단계 안내 문구(검색 준비 -> 웹 검색 -> AI 분석 -> 완료).
* **오류 안내 UI:** 사용자 친화적 오류 메시지 박스.
* **결과 카드 UI:**
  * 상단 헤더: 식별 작품명, 신뢰도 뱃지, 원제/작가/국가 메타데이터, `📋 요약 복사` 버튼.
  * 요약 키워드 배지: 메인 장르, 대표 호불호 요소, 완결 상태, 국내 서비스 플랫폼.
  * 정보 바: 원작 총 화수/권수, 한국어판 진행 상황, 초반 진입장벽 독자 평.
  * 스토리 & 매력: 도입부/초반 전개 요약(스포일러 엄금), 독자 반복 언급 매력 포인트.
  * 비슷한 작품: 독자들이 비교·추천하는 작품 목록.
  * 호불호 체크리스트 (26종): 카테고리별 전수 판정 및 스포일러 블라인드 토글.

## 5. AI 기능 및 데이터 파이프라인

### 5.1 기술 파이프라인 아키텍처

```text
사용자 작품명 입력
  │
  ▼
[FastAPI /api/analyze] (NDJSON Streaming)
  │
  ├─▶ 1단계: Tavily Search API (5개 쿼리 병렬 수집, 0~35% 진행률)
  │     · 쿼리 1: 작품 기본 정보 (작가, 원제, 줄거리)
  │     · 쿼리 2: 해외 독자 리뷰 (NovelUpdates, Reddit, Goodreads 도메인 타깃)
  │     · 쿼리 3: 국내 정식 연재처 (카카오페이지, 시리즈, 리디, 문피아)
  │     · 쿼리 4: 국내 독자 후기 (결말, 하차, 호불호 키워드)
  │     · 쿼리 5: 연재 이력·결말 (hiatus, dropped, completed)
  │     · URL 중복 제거 및 검색 결과 정제 (결과 없으면 422 반환)
  │
  ├─▶ 2단계: NVIDIA API 스트리밍 분석 (40~90% 진행률)
  │     · 모델: deepseek-ai/deepseek-v4.1-flash (OpenAI 호환 SSE 스트림)
  │     · 프롬프트: 검색 결과만 엄격한 근거로 반영, 환각 방지 지침
  │     · <think> 블록 제거 및 Pydantic JSON Schema 파싱
  │     · 스키마 검증 실패 시 오류 내용을 피드백하여 1회 자동 재요청
  │
  ├─▶ 3단계: 백엔드 카탈로그 확장 & 검증 (95~100% 진행률)
  │     · 26종 체크리스트 항목을 전수 매핑 (누락 항목은 '확인불가'로 보정)
  │
  ▼
[프론트엔드 NDJSON 리더]
  · progress 이벤트 실시간 수신 → 원형 게이지 업데이트
  · result 이벤트 수신 → 결과 렌더링 및 진행률 100% 완료 처리
```

## 6. AI 입출력 스펙

### 6.1 입력
* `title` (string): 웹소설 작품명 또는 원제 (1~200자, 공백 정규화).

### 6.2 출력 (`AnalyzeResponse`)
* `identified_title` (string): 식별된 대표 작품명.
* `original_title` (string): 원제 (확인 불가 시 '확인 불가').
* `author` (string): 작가명.
* `origin` (string): 원작 언어/국가 및 출처 정보.
* `confidence` (string): `높음` / `중간` / `낮음`.
* `genre_tags` (list[string]): 메인 장르 태그 (#키워드, 2~4개).
* `serial_status` (string): `완결` / `연재중` / `확인불가`.
* `original_length` (string): 원작 분량(총 화수/권수).
* `korean_releases` (list[KoreanRelease]): 국내 정식 플랫폼 및 연재 메모.
* `entry_point` (string): 초반 진입장벽에 대한 독자 평.
* `story_opening` (string): 도입부 및 초반 전개 요약 (중후반 스포일러 배제).
* `charm_points` (string): 독자 반복 언급 매력 포인트.
* `similar_works` (list[SimilarWork]): 비교·추천 작품 목록 (0~3개).
* `checklist` (list[ChecklistItem]): 26개 카탈로그 항목의 전수 판정 결과.

## 7. 예외 및 실패 처리 기준

1. **빈 입력:** 작품명이 비어 있거나 공백인 경우 API 호출을 사전에 차단하고 즉시 안내 표시.
2. **검색 자료 부족 (422):** 5개 병렬 검색 모두에서 유효한 검색 결과를 찾지 못했을 때 억지로 생성하지 않고 422 오류 및 구체적 안내 반환.
3. **환경변수/키 오류 (500):** `travily_key` 또는 `nvidia_key` 누락/인증 실패 시 즉각적인 500 오류 및 키 점검 안내 반환.
4. **API 사용량 한도 (429):** Tavily 또는 NVIDIA API 429 수신 시 "사용량 한도 도달 안내" 메시지로 변환.
5. **AI 응답 시간 초과 (504):** 서버 예산(110초) 또는 브라우저 예산(125초) 초과 시 안전하게 타임아웃 안내.
6. **스키마 검증 실패 복구:** NVIDIA 응답이 Pydantic 스키마와 불일치할 경우, 오류 내용을 모델에 다시 전달하여 1회 자동 재생성 시도.

## 8. 기술 스택 및 배포

* **Frontend:** HTML5, Tailwind CSS (CDN), Vanilla JavaScript (Single-file Component)
* **Backend:** Python 3.12, FastAPI, Pydantic v2
* **Search:** Tavily Search API (`travily_key`)
* **LLM Engine:** NVIDIA API (`nvidia_key`), Model: `deepseek-ai/deepseek-v4.1-flash`
* **Infrastructure:** Vercel Serverless Function (Python Runtime, maxDuration: 120s)
* **Repository:** `https://github.com/ilastoast-maker/codysseypub-A1-3`
* **Live Service:** `https://novel-rader.vercel.app/`
