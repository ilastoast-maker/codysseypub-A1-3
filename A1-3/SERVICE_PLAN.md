# Novel Radar 서비스 기획서

## 1. 서비스 개요

**Novel Radar**는 한국의 편/회차 단위 웹소설 결제 환경에서 사용자가 국내외 작품을 결제하기 전에 작품의 장르, 분위기, 전개 특성, 독자 반응, 번역 품질 등을 빠르게 파악할 수 있도록 돕는 AI 기반 웹소설 분석 서비스이다.

특히 해외 웹소설은 작품 정보와 리뷰가 외국어 사이트에 흩어져 있어 한국 사용자가 결제 전에 작품을 판단하기 어렵다는 문제를 해결하는 것을 목표로 한다.

## 2. 서비스 목적

- 웹소설 결제 전에 작품의 성격과 품질을 빠르게 파악할 수 있도록 한다.
- 해외 웹소설의 원어 제목을 그대로 검색할 수 있도록 한다.
- 외국어 자료를 검색하더라도 최종 결과는 한국어로 제공한다.
- 긴 리뷰를 모두 읽지 않아도 태그를 통해 작품 특징을 빠르게 이해할 수 있도록 한다.
- 장르뿐 아니라 번역/현지화 품질 정보까지 제공해 해외 작품 구매 판단을 돕는다.
- 검색 근거가 부족한 경우 AI가 임의로 정보를 만들어내지 않도록 한다.

## 3. 타겟 사용자

### 주요 타겟

편/회차 단위로 웹소설을 구매하는 **한국인 독자**.

### 세부 사용자 유형

- 해외 웹소설에 관심이 있지만 외국어 리뷰를 직접 찾아보기 어려운 사용자
- 작품을 여러 회차 결제하기 전에 장르와 작품 분위기를 확인하고 싶은 사용자
- 긴 리뷰나 커뮤니티 글을 모두 읽기보다 핵심 특징을 먼저 파악하고 싶은 사용자
- 해외 작품의 한국어 번역 또는 현지화 품질을 결제 전에 확인하고 싶은 사용자
- 한국에 정식 번역 제목이 알려지지 않은 작품을 원어 제목으로 검색하고 싶은 사용자

## 4. 사용자에게 제공하는 핵심 가치

### 4.1 원어 제목 그대로 검색

사용자는 해외 웹소설을 한국어 제목으로 번역할 필요 없이 영어, 중국어, 일본어 등 원어 제목을 그대로 입력할 수 있다.

예시:

```text
诡秘之主
Lord of the Mysteries
```

위 두 입력은 같은 작품을 서로 다른 언어 표기로 검색하는 예이다.

### 4.2 한국어 결과 제공

검색 대상과 참고 자료가 외국어이더라도 최종 분석 결과는 한국어로 제공한다. 이를 통해 사용자는 외국어 리뷰 사이트를 직접 읽지 않고도 작품의 특징과 평가를 이해할 수 있다.

### 4.3 태그 기반 빠른 작품 파악

장르, 분위기, 전개, 번역 관련 정보를 짧은 태그로 요약한다.

예시:

```text
#판타지
#미스터리
#느린초반
#세계관중심
#번역평가혼재
```

사용자는 전체 분석 글을 읽지 않아도 태그만으로 작품의 주요 특징을 빠르게 파악할 수 있다.

### 4.4 번역/현지화 품질 정보 제공

해외 웹소설은 작품 자체의 품질뿐 아니라 한국어 번역 품질이 독서 경험에 큰 영향을 줄 수 있다. 공개적으로 확인 가능한 리뷰와 자료가 있는 경우 번역/현지화 품질을 함께 분석한다.

공개 근거가 없으면 추측하지 않고 `#확인불가`로 표시한다.

### 4.5 검색 근거 제공

AI 결과만 단독으로 제공하지 않고 분석에 사용된 공개 웹 출처를 함께 제공한다. 사용자는 필요하면 직접 원문이나 리뷰를 확인할 수 있다.

## 5. 페이지 / 섹션 구성

Novel Radar는 하나의 반응형 페이지 안에 3개의 주요 섹션으로 구성된다.

### 5.1 홈 (`#home`)

- 서비스 브랜드와 핵심 메시지 표시
- 결제 전에 작품 정보를 확인한다는 서비스 목적 전달
- 해외 작품 원제 검색과 한국어 분석 기능 소개
- `작품 분석해보기` 버튼으로 분석 섹션 이동

### 5.2 소개 (`#about`)

세 개의 카드로 핵심 장점을 설명한다.

1. **원제 그대로 검색**
   - 한국어, 영어, 중국어, 일본어 등 다양한 제목 입력 지원
2. **한눈에 보는 태그**
   - 장르/분위기/전개/번역 정보를 짧은 태그로 표시
3. **한국어로 핵심 요약**
   - 해외 정보와 리뷰를 한국어 분석 결과로 제공

### 5.3 분석하기 (`#analyze`)

- 작품명 입력창
- 분석 버튼
- 로딩 상태 표시
- 오류 메시지 표시
- 작품 식별 정보
- 핵심 태그
- 스토리 전개
- 매력 포인트
- 주의/지뢰 및 번역 이슈
- 검색 근거/출처

### 5.4 메뉴 이동 방식

상단 네비게이션의 다음 메뉴를 통해 앵커 이동한다.

```text
홈 → #home
소개 → #about
분석하기 → #analyze
```

## 6. AI 기능 정의

### 6.1 기능명

웹소설 검색 기반 AI 분석

### 6.2 입력

- 웹소설 작품명 또는 원제
- 한국어/영어/중국어/일본어 등 지원
- 최대 200자

### 6.3 처리 과정

```text
사용자 작품명 입력
↓
FastAPI /api/analyze 요청
↓
Gemini + Google Search Grounding
↓
작품 식별
↓
공식/서지 정보, 독자 리뷰, 번역/현지화 근거 검색
↓
검색 근거 확보 여부 확인
↓
Gemini 구조화 분석
↓
Pydantic 스키마 검증
↓
한국어 분석 결과 반환
↓
프론트에서 태그/분석/출처 표시
```

구조화 JSON 생성이 불완전한 경우 백엔드에서 한 번 자동 재시도한다.

## 7. AI 출력 항목

- `identified_title` : 검색 근거로 식별된 작품명
- `original_title` : 원제
- `author` : 작가
- `origin` : 원작 국가/언어 등 출처 정보
- `confidence` : 작품 식별/분석 신뢰도
- `genre_tags` : 장르 태그
- `atmosphere_tags` : 분위기/전개 태그
- `translation_tags` : 한국어 번역/현지화 태그
- `story_arc_map` : 스포일러를 최소화한 스토리 전개 특성
- `charm_points` : 작품의 매력 포인트
- `warning_elements` : 호불호, 주의 요소, 번역 관련 이슈
- `evidence_note` : 근거의 충분성 및 주의사항
- `sources` : 검색 출처
- `search_queries` : AI가 사용한 검색어

## 8. 실패 처리 기준

### 빈 입력

작품명이 비어 있으면 API를 호출하지 않고 사용자에게 필수값 입력 안내를 표시한다.

### 검색 근거 부족

Google Search Grounding에서 근거 출처를 확보하지 못하면 추측으로 결과를 생성하지 않고 HTTP 422와 근거 부족 안내를 반환한다.

### 번역 평가 근거 부족

한국어 번역/현지화 품질 관련 공개 근거가 없으면 AI가 임의로 평가하지 않고 `#확인불가`로 표시한다.

### AI 구조화 출력 실패

Gemini가 JSON을 불완전하게 생성한 경우 1회 자동 재시도한다. 재시도 후에도 실패하면 사용자에게 분석 결과 생성 실패 안내를 표시한다.

### API/서버 오류

환경변수, 패키지 또는 AI API 호출 문제가 발생하면 HTTP 500/502 계열 응답을 사용하고 프론트에서 오류 메시지를 표시한다.

### 응답 지연

브라우저 요청이 설정된 제한 시간을 초과하면 요청을 중단하고 분석 시간 초과 메시지를 표시한다.

## 9. 반응형 UX

Tailwind CSS의 반응형 클래스를 이용해 모바일/태블릿/데스크톱에 대응한다.

- 모바일에서 입력창과 분석 버튼을 세로 배치
- 넓은 화면에서 입력창과 버튼을 가로 배치
- 소개 카드 모바일 1열 / 데스크톱 3열
- 분석 결과 모바일 1열 / 데스크톱 2열
- 실제 데스크톱과 휴대폰에서 배포 서비스 동작 확인

## 12. 서비스 차별점 요약

Novel Radar의 핵심은 단순 줄거리 요약이 아니라 **한국 사용자의 웹소설 결제 전 의사결정**을 지원하는 것이다.

특히 다음 네 가지를 차별점으로 한다.

1. 해외 작품을 원어 제목 그대로 검색할 수 있음
2. 외국어 자료를 활용하더라도 결과를 한국어로 제공
3. 태그만으로 작품 특징을 빠르게 파악 가능
4. 장르뿐 아니라 번역/현지화 품질까지 구매 판단 정보로 제공
