## 1. 서비스 기획

- ✅ **웹 서비스 아이디어 정의**
  - Novel Radar는 한국의 편/회차 단위 웹소설 결제 환경에서, 사용자가 국내외 작품을 결제하기 전에 작품의 특징과 품질을 파악할 수 있도록 돕는 AI 기반 웹소설 분석 서비스이다.
  - 해외 작품은 원어 제목으로 검색할 수 있고, 최종 결과는 한국어로 제공한다.
  - 상세 기획은 `SERVICE_PLAN.md`에 정리되어 있다.

- ✅ **목적 및 타겟 사용자 정의**
  - 목적: 범국가적 웹소설 콘텐츠를 결제 전에 빠르게 파악할 수 있도록 작품 정보, 독자 반응, 장르/분위기 태그, 번역 품질 정보를 제공한다.
  - 타겟: 편/회차 단위로 웹소설을 구매하는 한국인 독자, 특히 해외 웹소설을 직접 외국어 리뷰까지 찾아보기 어려운 사용자.

- ✅ **최소 3개 이상의 페이지/섹션 및 메뉴 이동 설계**
  - `#home` : 서비스 소개/메인 메시지
  - `#about` : 서비스 핵심 가치 설명
  - `#analyze` : 작품 검색 및 AI 분석
  - 상단 메뉴의 `홈 / 소개 / 분석하기` 링크로 각 섹션 이동 가능.

- ✅ **AI 기능 정의**
  - 입력: 웹소설 제목 또는 원제(한국어/영어/중국어/일본어 등)
  - 처리: Gemini + Google Search Grounding으로 작품 식별, 공식 정보, 독자 리뷰, 번역/현지화 근거를 조사한 뒤 구조화 분석
  - 출력: 작품 식별 정보, 장르 태그, 분위기/전개 태그, 번역 태그, 스토리 전개, 매력 포인트, 주의 요소, 검색 출처
  - 사용자 가치: 외국어 리뷰를 모두 읽지 않아도 한국어 요약과 태그로 작품의 장르/분위기/번역 품질을 결제 전에 빠르게 파악할 수 있음.

## 5. AI 기능 UX 최소 기준

- ✅ **사용자 입력 UI**
  - 작품명 입력창과 `분석하기` 버튼 제공.

- ✅ **AI 결과 화면 출력**
  - 작품 식별 정보, 태그, 스토리 전개, 매력 포인트, 주의/번역 이슈, 검색 출처를 화면에 표시하도록 구현.

- ✅ **실패 처리 안내**
  - 빈 입력 → 필수값 안내
  - API 오류(4xx/5xx) → 서버 오류 메시지 표시
  - 지연/타임아웃 → 55초 후 시간 초과 안내
  - AI 구조화 JSON 불완전 응답 → 백엔드에서 1회 자동 재시도
  - Gemini 무료 쿼터 초과(429) → 긴 SDK 오류 대신 사용자용 안내 메시지 반환

## 6. AI API 연동 (Vercel Serverless Functions - Python)

- ✅ **`api/` Python 엔드포인트 구현**
  - `GET /api/health`
  - `POST /api/analyze`

  - `google-genai` SDK를 사용.

  - 검색 근거 부족, API 키 문제, 쿼터 초과, 구조화 응답 실패 등을 구분하여 처리.

- ✅ **`requirements.txt` 의존성 정의**
  - `fastapi`
  - `google-genai`
  - `pydantic`

- ✅ **프론트의 `/api/...` 호출**

  - JSON 응답 검증 및 화면 렌더링 구현.
