## 1. 서비스 기획

- ✅ **웹 서비스 아이디어 정의**
  - Novel Radar는 한국의 편/회차 단위 웹소설 결제 환경에서, 사용자가 국내외 작품을 결제하기 전에 작품의 특징, 전개 성향, 독자 매력 포인트, 그리고 끝까지 읽어야만 알 수 있는 호불호/지뢰 요소를 사전에 파악할 수 있도록 돕는 AI 기반 웹소설 분석 서비스이다.
  - 해외 작품은 한국어 번역명을 몰라도 원어 제목(영어/중국어/일본어 등) 그대로 검색할 수 있고, 최종 분석 결과는 한국어로 제공한다.
  - 상세 기획은 `SERVICE_PLAN.md`에 정리되어 있다.

- ✅ **목적 및 타겟 사용자 정의**
  - 목적:
    1. 소개(Discovery): 좋은 국내외 작품의 도입부 설정과 매력 포인트를 한국 독자에게 소개 (중후반 스포일러 엄금).
    2. 사고 방지(Risk Prevention): 연재 중단·장기 휴재 이력, 슬픈 결말·주인공 사망, 억지 전개·자기복제 등 유료 결제 후 낭패를 겪는 지뢰 요소를 사전 차단 (결말 관련 항목은 🔒 블라인드 처리).
  - 타겟: 편/회차 단위로 웹소설을 구매하는 한국인 독자, 특히 해외 웹소설 정보를 직접 외국어 리뷰 사이트까지 찾아보기 어려운 사용자.

- ✅ **최소 3개 이상의 페이지/섹션 및 메뉴 이동 설계**
  - `#home` : 서비스 소개/메인 슬로건 ("결제하기 전, 선발대에게 물어보세요")
  - `#about` : 서비스 3대 핵심 가치 설명 (원제 검색, 키워드 요약, 스포일러 없는 사고 방지)
  - `#analyze` : 작품 검색 및 AI 분석 (원클릭 추천 예시, 진행률 링, 결과 카드, 26종 체크리스트, 복사 기능)
  - 상단 메뉴의 `홈 / 소개 / 분석하기` 앵커 링크로 각 섹션 스무스 스크롤 이동 가능.

- ✅ **AI 기능 정의**
  - 입력: 웹소설 제목 또는 원제(한국어/영어/중국어/일본어 등)
  - 처리: Tavily 검색 API(5개 쿼리 병렬 수집) + NVIDIA API (DeepSeek V4.1 Flash) 스트리밍 분석으로 작품 식별, 독자 리뷰, 국내외 플랫폼, 결말 및 호불호 근거를 조사한 뒤 Pydantic 스키마 기반 구조화 분석
  - 출력: 작품 식별 정보, 대표 장르 키워드, 원작 연재상태 및 총 분량, 국내 정식 서비스 플랫폼, 진입장벽 독자평, 도입부/초반 전개 요약, 매력 포인트, 유사작 추천, 26종 호불호 체크리스트(스포일러 방지 클릭 공개)
  - 사용자 가치: 외국어 리뷰를 읽지 않아도 작품의 특징, 분량, 국내 플랫폼, 지뢰 요소를 결제 전에 확실히 파악하여 합리적인 소비 가능.

## 5. AI 기능 UX 최소 기준

- ✅ **사용자 입력 UI**
  - 작품명 입력창과 `분석하기` 버튼, 원클릭 추천 검색어 칩 제공.

- ✅ **AI 결과 화면 출력**
  - 원형 Progress Ring 게이지(0~100%)와 실시간 단계별 진행 문구 표시.
  - 식별 작품명, 신뢰도 뱃지, 대표 키워드, 분량/연재 정보 바, 도입부 소개, 매력 포인트, 유사작, 26종 체크리스트를 화면에 표시.

- ✅ **실패 처리 안내**
  - 빈 입력 → 사전 차단 및 필수값 입력 안내
  - 검색 결과 없음 → 422 서버 오류 안내 메시지
  - API 키 설정 오류 → 500 환경변수 점검 안내
  - API 한도 초과 → 429 친절한 사용량 한도 안내
  - 응답 지연/타임아웃 → 서버(110초) 및 브라우저(125초) 초과 시 안내 메시지
  - AI JSON 스키마 불일치 → 백엔드에서 1회 자동 재요청 복구 시도

## 6. AI API 연동 (Vercel Serverless Functions - Python)

- ✅ **`api/` Python 엔드포인트 구현**
  - `GET /api/health` : 서버 상태 및 Tavily / NVIDIA 키 등록 여부, 모델 정보 반환
  - `POST /api/analyze` : NDJSON 스트리밍 방식으로 실시간 진행률과 최종 결과 반환

- ✅ **AI API 호출 및 결과 반환**
  - Tavily Search API를 통한 5개 쿼리 병렬 검색 (0~35% 진행률).
  - NVIDIA API (DeepSeek V4.1 Flash) 스트리밍을 통한 근거 기반 구조화 JSON 생성 (40~90% 진행률).
  - Pydantic 스키마 검증 및 26종 카탈로그 전수 확장 (누락 방지).

- ✅ **`requirements.txt` 의존성 정의**
  - `fastapi`
  - `pydantic`

- ✅ **프론트의 `/api/...` 스트리밍 호출**
  - `fetch('/api/analyze', { method: 'POST', ... })`로 호출하고 `ReadableStream`을 통해 NDJSON 파싱.
  - 실시간 이벤트(`progress`, `result`, `error`) 처리 및 UI 바인딩.
